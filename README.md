# Retroarch-Updater
Update your Retroarch on windows with one click :ghost: with fastest method. :bicyclist:

There was a Retroarch updater made years ago i try a few times but its very slow and download speed is not optimal. Also its realy bothersome to download Retroarch 7z file manualy from their website each time nightly version gets updated.So i created terminal based updater only need one click.

> [!NOTE]
I dont use 7-Zip due to eats all my RAM and CPU on big files (Winrar is better), thats why this is in aportable form also you can swap the folder on any computer will work fine.

> [!IMPORTANT]
You can run **Retroarch (Update).cmd** file daily it will check date of your .7z file date and update if its outdated (DAILY)

# Make Sure Use It In Correct Order
> [!IMPORTANT]
Step 1 **Create a Folder Called RetroArch-Win64**\
Step 2 **Create a Folder Called 7z inside RetroArch-Win64**\
Step 3 **Download 7-Zip Portable Version (7-Zip Extra)** https://www.7-zip.org/download.html \
Step 4 **Extract All Files to 7z Folder inside RetroArch-Win64**\
Step 5 **Execute Retroarch (Update).cmd** OUTSIDE of the RetroArch-Win64 folder. (IF RetroArch-Win64 is in D:\RetroArch-Win64 run CMD file in D:\ NOT in the same folder !!)\
Step 6 **Press 1 To And Wait until its done**
